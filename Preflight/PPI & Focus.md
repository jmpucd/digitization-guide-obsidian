# PPI & Focus

Part of [[General Preflight]] (step 3). Goal: position and focus the camera so the object is captured at the correct **pixels-per-inch**. With the iXH / Capture One CH / DT Auto Column you can use **Auto-PPI**, which moves the column for you.

> [!info] What PPI to use
> 400 ppi for bound volumes, documents, oversized items · 600 ppi for photographs and postcards · film by long-edge pixel count. See [[Imaging Standards by Material Type]].

---

## Steps

1. Place a representatively sized object (or your target) on the surface so the whole object is in frame.
2. Open **Live View** — the icon in the Camera tool, or **Window → Live View**.
   ![[preflight-live-view-icon.jpg]]
3. Open the **Camera Focus** tool and enter the desired **Target Resolution** (e.g. type `400`).
   ![[preflight-camera-focus-400ppi.jpeg]]
4. In Live View, zoom in on the target. In the **Live View Focus Meter**, select **Pick focus area using** (turns orange) and place the focus box on the **center of the target**.
   ![[preflight-focus-meter-pick-area-1.jpeg]]
   ![[preflight-focus-meter-pick-area-2.jpeg]]
5. Press **Start** in Camera Focus. The camera/column adjusts height and focus to hit the target PPI. The button changes to **Stop** — keep your cursor near it and watch the column move in case it needs stopping.
   ![[preflight-camera-focus-start.jpeg]]
6. When focusing finishes, close Live View and capture an image of the target.
7. **Verify** with the **Capture Resolution Ruler**: select the ruler icon → **Show**, measure one inch against the target's markings to confirm you're at the intended PPI. Uncheck **Show** when confirmed.

> [!note] How Auto-PPI behaves
> Once set, refocusing changes the PPI if the object moves closer/farther from the camera. So if your object depth differs from the target (e.g. a thick mat), **refocus on the object** without changing the entered PPI — the column compensates.
