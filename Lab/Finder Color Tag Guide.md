# Finder Color Tag Guide

How we track a session's progress with macOS Finder color tags. Applies to both **session folders** and the TIFF folders in **Archive Tiff**.

| Color | Meaning |
|---|---|
| 🟢 **Green** | Completely finished (session **and** TIFF folders) |
| 🟣 **Purple** | Cropped but **not** exported |
| ⚪ **Grey** | Not page-split yet |
| 🟡 **Yellow** | Page-split but **not** cropped |
| 🔴 **Red** | Something wrong — needs review |

## Where this fits

- Set **Yellow** after [[Page Splitting]], **Purple** after [[Cropping & Straightening]], **Green** after [[Export]] / [[Quality Control]].
- **Red** anywhere an issue is found — log it on the QC sheet.
- In the [[Session Handoff (digi)]] tool, the checkin **stage** (crop / qa-qc / done) plays a similar role for sessions in the queue.
