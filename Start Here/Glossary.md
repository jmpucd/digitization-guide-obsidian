# Glossary

- **PPI** — pixels per inch across the original object; how we set capture resolution. See [[PPI & Focus]].
- **Bit depth** — tonal steps per channel (8-bit / 16-bit). See [[Image Types & File Formats]].
- **Color space / profile** — the range of colors a file describes (we use Adobe RGB (1998)). See [[Color Management & Calibration]].
- **LCC** — Lens Cast Calibration; corrects lens cast and evens out lighting. See [[LCC (Lens Cast Calibration)]].
- **White balance** — neutralizing color cast off a known target patch. See [[White Balance]].
- **Curve** — tone-response curve in Base Characteristics (Linear Response vs Linear Scientific). See [[Mode, Profile & Curve]].
- **Capture One CH** — Cultural Heritage edition of Capture One; adds Mode + pre-built CH ICC profiles.
- **Recto / Verso** — front / back of a page. Bound volumes split into both; flat art is usually recto-only.
- **Primary Variant** — in a multi-image selection, the one with the thicker white border that edits apply to. See [[Page Splitting]].
- **Session** — a Capture One session folder (`Captures/`, `Output/`, `Selects/`, `.cosessiondb`).
- **`.cosessiondb`** — the Capture One session database holding crops, ratings, color tags.
- **FADGI** — Federal Agencies Digital Guidelines Initiative; imaging best-practice star ratings (ISO 19264). See [[Color Management & Calibration#FADGI]].
- **TIFF** — our uncompressed archival master format.
- **Master vs derivative** — the preserved high-quality file vs. smaller access copies made from it.
- **`digi`** — our session-handoff tool (park/checkout/checkin). See [[Session Handoff (digi)]].
- **`archive-project`** — our archiving tool (MD5-verified transfer to CentOS + Sheet log). See [[Archiving & Delivery (archive-tool)]].
- **Park / Checkout / Checkin** — move a session to the queue / grab it locally with a lock / return it and release the lock.
- **Archive queue / `.archive-source`** — a staging folder for finished projects; the marker file that makes the archive tool accept it.
