# Capture & Subsequent Boxes

Part of [[Large & Flat Art]]. How to image the items in a box, and the **shortcut** for starting each new box without a full preflight.

---

## Imaging a box

1. In the **Library**, each item has a folder named for its **accession number** (written on the item's mat, sometimes the item).
2. Open the portfolio box; carefully remove an item; lift the mat to read the accession number.
3. Set that item's folder as **Capture Folder**.
   - If the spreadsheet missed an item, create a folder in the Capture folder and **Add to Favorites** in Library.
4. **Reset Capture Naming.**
5. Place the item; carefully fold open the mat; **remove the mylar**.
6. **First item — refocus:** mats change the focus plane.
   - Open Live View, **focus on the print itself** (don't change the PPI).
   - Usually you can keep that focus for the whole box (mats are similar depth) — but **re-check** thicker/thinner items and refocus as needed.
7. **Capture.** Matted items are **recto only** — do not fold the item over.
8. Replace the **mylar** and return the item to the box.
9. Repeat through all items in the box.

## Starting a subsequent box (no full preflight)

After the first box, skip the full preflight:

1. Open the session folder for the box you're working on.
2. Set the **Preflight** folder as Capture Folder; confirm naming is `DestinationFolderName_###`.
3. Base Characteristics: **Mode** Photography · **ICC** `Flat Art Reproduction – LED DT Photon` · **Curve** Linear Scientific.
   ![[flatart-base-characteristics.png]]
4. Capture **one frame with both targets** (Golden Thread + larger target) in frame.
5. Reapply presets: **LCC** `No_Glass_400_SHREM` · **White Balance** `No_Glass_400PPI`.
6. Set Base Characteristics **ICC** to `NoGlass_400ppi_SHREM_111225`.
7. Production tab: **ICC Profile → Copy From Last** (not Defaults).
   ![[flatart-copy-from-last.png]]
8. Set the first item's folder as Capture Folder.
9. Place the item, remove mylar / open mat.
10. **Refocus only if the mat depth differs** from the last box.
11. **Reset Capture Counter.**
12. Image, and continue through the items.
