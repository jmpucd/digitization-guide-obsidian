# Sidebar order (Custom Sort)

This note defines the **local file-explorer order** for the [Custom Sort](https://github.com/SebastianMC/obsidian-custom-sort) plugin. It is **not** published (excluded in `publish.json`) and Obsidian Publish ignores it entirely — the published site's order is set separately via **Publish → Change site options → Customize navigation**.

To apply after editing: enable the Custom Sort plugin and click its ribbon icon (or run *Custom Sort: sort*).

Folders not listed sort alphabetically after the listed ones.
