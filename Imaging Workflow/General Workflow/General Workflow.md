# General Workflow

The shared imaging phases every project follows, in order. The per-material guides ([[Bound Volumes]], [[Large & Flat Art]]) reference these and add only their own steps.

1. **[[Capture]]** — create the session, set the capture folder + naming, and image the material.
2. **[[Cropping & Straightening]]** — crop and straighten each image (manual, scripts, Stream Deck) + first-round QC.
3. **[[Export]]** — export TIFF masters to the material standard (two-recipe pattern).
4. **[[Quality Control]]** — final QC in Photo Mechanic.

Then hand off: [[Processing Pipeline Overview]] → [[Session Handoff (digi)]] → [[Archiving & Delivery (archive-tool)]].
